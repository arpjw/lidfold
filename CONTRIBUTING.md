# Contributing

Thanks for helping make LidFold useful and trustworthy.

Before opening a pull request:

1. Keep new behavior on-device and avoid adding telemetry.
2. Do not copy commercial app code, assets, names, or marketing copy.
3. Run `swift test` and include manual test notes for hardware-dependent changes.
4. Keep undocumented API usage isolated and explain the compatibility risk.
5. Discuss large dependency or architecture changes in an issue first.

Bug reports should include the Mac model, chip, macOS version, whether an external display
was attached, and the smallest set of steps that reproduces the problem. Do not attach screen
recordings containing private information unless you have redacted them.
